# Projects

An index of the work worth finding. The ones with writeups are on
[telaak.dev](https://telaak.dev/#work).

## Current

- **[openHC](https://github.com/The1TrueJoe/openHC)** — open, kernel-up firmware for
  Control4 controllers: a modern Linux kernel and root filesystem built from source,
  a Rust installer that refuses to guess the board, and a documented way back to stock.
  [Docs →](https://telaak.dev/openHC/)
- **[sgx545-ce](https://github.com/The1TrueJoe/sgx545-ce)** — Linux driver for the
  Imagination PowerVR SGX545 GPU in the Intel Atom CE5310.
- **[t2i-zephyr](https://github.com/The1TrueJoe/t2i-zephyr)** — custom Zephyr firmware for
  the RTI T2i Zigbee + RF remote.
- **[openSpeakerPoint](https://github.com/The1TrueJoe/openSpeakerPoint)** — Buildroot
  firmware for the 2006 Control4 SpeakerPoint.
- **[CEC-Dongle](https://github.com/The1TrueJoe/CEC-Dongle)** — HDMI-CEC dongle for
  Control4.
- **[access-controller](https://github.com/The1TrueJoe/access-controller)** — ESP32 access
  controller for my garage door.
